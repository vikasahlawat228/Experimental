## How skills get captured

When a module solidifies, `consolidate-to-second-brain` decides whether the learning includes a *repeatable move* worth keeping (not just a fact). If yes, it proposes a new `SKILL.md` in `../../../team-brain/skills/<skill-name>/`, and logs it here. The learning side never holds the skill itself; only the pointer.
