# people/

One file per teammate or frequent collaborator. Kept light: what they own, what they care about, how we work together. For me, not a CRM. No sensitive personal information — no phone numbers, no home addresses, no health information, nothing that wouldn't be appropriate in a work doc.

File naming: `firstname-lastname.md` or `firstname-l.md` if disambiguation needed.

Suggested sections:

```
# <Name>

> As of YYYY-MM-DD: <Role, what they own, one note about how we work together>.

## What they own

## What they care about

## How to reach them

## Notes for me
- Things I learned about how they like to work, what triggers good
  collaboration, what to avoid.
```
